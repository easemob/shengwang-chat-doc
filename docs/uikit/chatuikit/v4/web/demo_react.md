# 体验 React Demo

React UIKit 提供会话列表、聊天和通讯录等业务界面，可通过示例项目了解单聊、群聊与界面定制能力。

## 获取示例项目

访问 [React UIKit 源码](https://github.com/easemob/easemob-uikit-react)，根据项目 README 和版本标签查看示例代码及运行方式。示例中的应用配置需按声网项目适配，SDK 的初始化参数和用户 Token 登录方式以本站集成文档为准。

## 接入声网项目

1. 按 [入门指引](beginner_guide.html#集成步骤) 注册开发者账号，创建项目、开通即时通讯 IM 服务并获取 App ID。
2. 准备同一项目下的两个 IM 用户及用户 Token。
3. 按 [快速开始](chatuikit_quickstart.html) 或 [React 集成单群聊 UIKit](chatuikit_integrated_react.html) 安装依赖并初始化，使用两个独立登录环境验证单聊和群聊消息收发。

生产环境由业务服务器获取并分发用户 Token，App 证书和 App Token 仅保存在服务端。
