# 体验 Vue Demo

Vue 3 社区 Demo 展示会话列表、聊天、通讯录、群组管理及 UIKit 的配置效果，可用于了解组件与页面交互。

## 在线体验

访问 [在线 Demo](https://webim-vue3.easemob.com/)，体验单聊、群聊和联系人管理。在线 Demo 使用其演示服务，与自己的声网项目分开。

## 查看源码与本地运行

[Demo 源码](https://github.com/Easemob-Community/easemob-demo-vue3) 提供环境要求、依赖安装和本地启动说明，请使用与所选版本对应的 README。

该社区 Demo 默认使用 App Key 配置。接入声网项目时，需要先核对所用 SDK 适配器对 App ID 初始化和用户 Token 登录的支持，并改造 Demo 的配置与登录流程；不能将声网 App ID 直接填入 Demo 的 AppKey 输入框。声网的项目与鉴权准备见 [入门指引](beginner_guide.html#集成步骤)。
