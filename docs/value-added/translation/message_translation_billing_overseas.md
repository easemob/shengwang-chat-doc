# 海外计费说明

本文介绍消息翻译的海外计费规则。国内计费规则详见 [国内计费说明](message_translation_billing_domestic.html)。

## 功能开通

消息翻译为增值服务，使用前请先在 [声网控制台](https://console.shengwang.cn/overview) 的 **套餐包 > 预付费套餐包 > 即时通讯 IM** 页面开通。

## 配额说明

翻译字符数是指一个自然月内累计翻译的字符数量。

单次翻译请求最多支持 10,000 个字符。翻译字符数按照以下公式计算：

**翻译字符数 = 源文本字符数 × 目标语言数量**

例如，将一段包含 500 个字符的文本翻译为 4 种目标语言，本次请求产生的翻译字符数为：

`500 × 4 = 2000 个字符`

## 计费说明

- **海外数据中心**：1000 元/月，包含 500 万翻译字符配额。超出部分按 0.2 元/1000 个翻译字符计费；不足 1000 个字符的部分按 1000 个字符计算。

计费标准详见 [计费策略](/docs/product/pricing_policy.html#消息翻译)。
